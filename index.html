EL CONCEPTO

¿Cómo funcionará?

La integración real se construirá por etapas para proteger las wallets y comprobar correctamente las transacciones.

01

Compra confirmada

El servidor detectará una compra elegible y confirmada de $WRACE.

02

Wallet participante

La dirección pública aparecerá abreviada como corredor.

03

Carrera rápida

Las wallets participarán en una ronda animada de aproximadamente dos minutos.

04

Resultado verificable

El ganador y la transacción del premio aparecerán públicamente.

JUEGO JUSTO

Reglas propuestas

Una entrada

Una wallet tendrá una sola participación en cada ronda.

Compra mínima

La cantidad mínima será configurada y publicada antes del inicio.

Confirmación

Las compras deberán estar confirmadas en la blockchain.

Prueba pública

La wallet ganadora y el pago podrán revisarse en Solana.

🔒 Seguridad de las wallets

Wallet Racers nunca solicitará frases semilla, contraseñas ni claves privadas. Los premios reales deberán salir de una wallet separada, con saldo limitado. Nunca coloques una clave privada dentro de este archivo ni en GitHub.
